# Changelog

## 3.2.0 — Evidence-driven path security

- Added deterministic measurement-record exports, privacy-safe report views, and robust local P50/P95/P99 monitoring baselines.
- Added conservative BGP security rules, alert fingerprint suppression, controlled packet-integrity and Cilium Hubble evidence imports.
- Added approval-gated Globalping request previews, CycloneDX SBOM generation, and remote-agent nonce replay protection.
- Kept all active network measurements bounded and opt-in; imported enterprise evidence never becomes an unsupported Internet-path claim.

All notable changes to AegisRoute are documented here.

## 3.1.0 — 2026-10-18

- Added bounded RIS Live evidence collection and a normalized control-plane timeline.
- Added approval-gated RIPE Atlas measurement creation with a no-cost preview mode.
- Added reproducible incident bundles, optional HMAC manifests, OTLP/HTTP export, and a Grafana starter dashboard.
- Added adaptive measurement profiles and calibrated observation-completeness confidence.
- Hardened the read-only agent with destination policy, rate limits, response signatures, TLS, and optional mTLS.
- Added import-only IOAM evidence for authorized operator environments.

## 3.0.0 — 2026-10-05

- Rebranded the complete project as **AegisRoute**.
- Added cross-protocol route fusion, routing-security enrichment, history, alerting, service diagnostics, remote reporting, and research-grade Scamper integrations.
- Added professional project documentation, CI, contribution and security guidance, and a terminal showcase asset.
