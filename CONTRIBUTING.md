# Contributing to AegisRoute

Thank you for improving defensive route intelligence.

1. Open an issue before proposing a large feature or a behavior-changing measurement claim.
2. Keep the zero-third-party-Python-dependency baseline intact unless there is a compelling reason not to.
3. Add or update offline parser tests for changed behavior.
4. Run `python3 -m unittest discover -s tests -v` before opening a pull request.
5. Never commit targets, API tokens, route captures, database files, or reports that reveal sensitive network information.

Claims about route ownership, aliasing, loss, or outages must retain the project's evidence/confidence semantics and alternative explanations.
